# 미완료 작업 / 검증 목록

## P0 — 최신 사용자 요청 (아직 반영 안 됨)
지역별 독립 figure.photo 6개를 제거하고 각각 기존 day-intro 헤더 배경으로 이동. Day1 하카타, Day2 가족 유후인(커플 하카타 도착용 사진 없음), Day3 가족 다자이후/커플 모모치, Day4 가족 라라포트/커플 다이묘. 기존 이미지 URL과 data-fallback 재사용 가능. 모드별 사진 노출 및 흰 글자·dim 대비, 간격, 스크롤 스파이 검증. 본문 별도 지역 사진만 제거; 전체 메인 커버/맛집/투어 이미지 유지.

## P1 — 이미지 오류
사용자가 여러 번 사진 누락을 보고함. 현재 사진 URL 다수 외부 링크, 실재 여부 및 매장 일치 여부 검증 부족. 신규 영상 추천 17개 이미지 링크 추가 및 6개 교체 커밋은 있었지만 실제 전체 로딩 테스트 미완료. 지인추천 신규 3개는 사진 미등록 가능성. 전 카드 실제 브라우저에서 naturalWidth, HTTP 상태, 콘텐츠 유형, 매장/메뉴 일치 검증. 저작권/이용 조건 확인 후 로컬 assets/food/에 저장 가능한 사진 우선. 출처 표시. 무관한 식당 이미지 제거(스시사카바에 사시스 참고 사진 적용된 적 있음). 실패 시 지도에서 사진 보기 링크 유지. 임의 URL 생성 금지.

## P1 — 지도
Google Maps 선호. 여러 번호 마커만 보여도 됨. 현재 임베드 방식은 선택된 1개 장소만 표시 가능. My Maps 접근 문제 있었음. API 키/유료 서비스 임의 도입 금지. 적절한 방식 확인하고 실제 동작 검증. 도보 15분 기준, 나머지 대중교통; 실제 경로 시간은 미검증.

## P1 — 일정 실현 가능성
가족 숙소 짐 보관 정책 공식 확인. 첫날/마지막날 캐리 서비스 또는 역 보관 검토. 18일 저녁 아빠 합류·늦은 주문, 19일 버스투어 지연/형욱 합류/5인 식사, 21일 공항 이동 여유 확인. 아직 예약 미확정. 투어 상품 가격·시간 재확인. 스시로 텐진점 정확 지점, 지인추천 주소·평점·예약·사진 검증.

## P2 — 코드 및 QA
iOS Safari 화면, 320~430px 폭, desktop, 첫 진입 top, hash deep link, history restore, 탭 스크롤 spy, mode persistence, checklist, 카테고리/출처/검색/평점/예약 필터 조합. 기존 추천 탭 삭제 후 기존 추천 카드는 전체에서 접근 가능해야 함. 이미지 실패 시 빈 공간·레이아웃 이동 점검. CSS override 중복 정리, 안전한 범위에서 구조 개선. 실제 테스트 전 완료 주장 금지.
