# UI/UX 요구사항

- 이름 Merry Fukuoka! 🎄, 메인 헤더 Georgia Bold, FUKUOKA, JAPAN 및 기간. 기존 후쿠오카 풍경 원복 상태 유지. 공유 썸네일 자동 방식, 제목·설명 유지.
- Liquid Glass / 최신 iOS 스타일. 하단 고정 일정·맛집·준비 메뉴, 가족/커플 선택 pill. 스크롤 다운 시 아이콘·보조 라벨 축소, 업 시 복원. 상단 고정 영역 최소화.
- 일정 날짜 탭 sticky, family Day1–4 / couple Day1–3. 날짜와 제목 겹침 금지. 초기 진입은 상단, 명시적인 #d1 등 해시만 해당 위치. 맛집/준비에서는 날짜 탭 숨김.
- 일정 Day 구분선 풀폭, 소제목으로 일정 그룹화, 시간과 중요 이벤트 명확히. 불필요한 박스/세로선 최소화. 가족/커플 색상 구분.
- 최신 미반영 요구: 지역별 독립 사진 블록 제거하고 기존 대표 사진을 Day 제목(day-intro) 배경으로 이동. 흰 글씨, dim 대비 확보. 날짜/제목/소제목 유지. 가족·커플 날짜별 서로 다른 사진 필요. 커플 19일은 기존 사진 없음: 하카타 도착 이미지 재사용 가능(임의 결정임을 명시). 전체 메인 헤더/맛집 사진/투어 사진은 건드리지 않음.
- 맛집 카드 사진 비율 기존 4:3, 출처 링크, 음식 위주. 카테고리 아이콘. 출처 탭 전체/저장 목록/영상 추천/지인추천. 개별 추천 태그는 '윗집 언니 추천', 분홍색. 이치란 본점은 영상+지인 중복 출처, 카드 중복 없음.
- 공통 CSS 구조 유지. iPhone safe area, 글자 겹침, 탭 넘침, 이미지 fallback, 스크롤 위치를 확인.
