# Merry Fukuoka! — Codex 작업 지침

이 저장소의 fukuoka/ 웹사이트를 유지보수한다. 한국어로 소통한다. 사용자는 웹 퍼블리셔이며 실제 코드 변경과 배포를 선호한다.

## 작업 규칙
- 수정 전 현재 브랜치의 실제 index.html을 읽는다. 이전 대화의 코드나 오래된 로컬 복사본으로 덮어쓰지 않는다.
- HTML/CSS/JS 기반 정적 사이트 유지. 빌드 도구, 프레임워크, 유료 API는 요청 없이는 도입하지 않는다.
- 모바일 우선, iPhone Safari 및 데스크톱 대응. 의미 있는 시맨틱 마크업, 접근성, 키보드 포커스, 대비, 안전 영역, 기존 기능 보존.
- 간결한 클래스명과 재사용 가능한 공통 CSS 선호. 중복 override를 정리할 때 기존 화면 회귀 주의.
- 가족/커플 audience 필터, 날짜 탭, 스크롤 스파이, 첫 진입 상단, 해시 딥링크, localStorage 체크리스트 유지.
- 사진은 공식/실제 방문 후기 출처를 검증하고 매장·메뉴가 다른 사진을 실제 사진으로 표시하지 않는다. 참고 이미지는 명시한다. 허용된 이미지의 로컬 저장 우선, 외부 URL 실제 응답/디코딩 검사. 이미지 오류 시 정상 fallback.
- 구글맵 평점·예약·가격·영업시간·좌석 등 확인되지 않은 정보는 미확인으로 표시한다. 예약 링크 존재와 빈자리 확정을 구별.
- 개인정보 보호: 예약번호, 티켓번호, 연락처 등 추가 금지. 공개 GitHub Pages이며 noindex는 접근 통제가 아니다. 불필요한 개인정보를 추가하지 않는다.
- 수정 범위를 좁게 유지하고 변경 전후 diff 검토. JS 구문 검사, HTML 검사, 모바일 렌더링·가족/커플 모드·필터·해시·스크롤·이미지 검사 수행. 테스트하지 못한 항목은 명시.
- 사용자 요청이 실제 반영이면 GitHub 변경 성공 여부와 배포 검증 여부를 구분해 보고. 미실행 작업을 완료라고 말하지 않는다.
- README.md, DESIGN.md, TRIP_PLAN.md, TODO.md를 먼저 읽되 최신 소스와 사용자 최신 지시가 우선.
